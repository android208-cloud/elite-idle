# Контейнеры с грузом после боя — данные оригинала

Источник: `markmoxon/elite-source-code-bbc-micro-disc`, файлы
`1-source-files/main-sources/elite-ships-*.asm`. Правило записано в комментарии
к первому байту блюпринта каждого корабля:

```
EQUB 0 + (2 << 4)      \ Max. canisters on demise = 0
                       \ Market item when scooped = 2 + 1 = 3 (slaves)
```

Младший ниббл — **сколько контейнеров корабль выбрасывает при уничтожении**.
Старший ниббл — **какой товар в них** (индекс + 1). Если старший ниббл 0,
товар выбирается случайно из 0–7 (Food..Computers). Значение 0xF — особое
(«предметы пришельцев», `alien items`).

## Что это значит для игры

- **Sidewinder — самый частый пират раннего этапа — не роняет ничего.**
  Это не баг, а баланс: в нём сидит бедняк, и в оригинале он пустой.
- **Python (5) и Cobra Mk III (3)** — настоящая добыча. При этом Python
  как пират роняет 2, а как торговец — 5: торговец гружёный.
- **Gecko, Adder, Fer-de-Lance, Asp, Viper, Thargoid — пустые.**
- **Астероиды пустые**, но их осколки (`splinter`) при подборе дают
  минералы, а обломки (`plate`) — сплавы. Это уже не «контейнеры», а
  отдельный случай подбора.

## Подбор

- Нужен **топливосборщик** (`fuel scoops`). Без него контейнер при
  касании разбивается.
- Контейнер занимает **место в трюме** (1 тонна на товарах 0–12).
- Товар из контейнера **не покупался** — при продаже он идёт по цене
  системы и считается чистой прибылью.
- Контейнер с контрабандой (рабы, наркотики, оружие) при подборе
  **повышает правовой статус** ровно так же, как покупка на рынке.
