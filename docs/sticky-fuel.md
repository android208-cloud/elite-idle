# Липкая карточка «Топливо» в ангаре — как устроена и почему так

Решение выработано в §131–§131.12 (см. `session_log.md`). Здесь — итог: что
именно стоит в коде, какое правило за ним и какие варианты уже проверены и
отвергнуты. Переделывать не надо; если понадобится менять — знать, что уже
ломали.

## Что требуется

Пользователь: «сперва карточка корабля уезжает вверх вместе с остальным
списком, затем карточка „топливо“, дойдя до нижнего края шапки, закрепляется
там, а остальной список уходит уже под „топливо“».

Плюс вид, который он выбрал после долгого перебора:

* **снизу** — скругление круглое всегда, сквозь дуги нижних углов видно
  уползающую под карточку, тень её притеняет («нежный эффект»);
* **сверху** — скругление тоже круглое и тоже не пропадает, но «дырка» вне
  дуги закрашена цветом страницы: карточка висит на шапке, мелькать там нечему;
* вокруг карточки **ничего не нарисовано** — ни подложки, ни полос, форма не
  меняется на ходу.

## Что стоит в коде

`src/ui/main.ts`, `hangarScreen()`:

```html
<div class="sticky-fuel"><div class="card">…Топливо…</div></div>
```

`src/ui/styles.css`:

```css
main { padding: 0 16px 16px; }              /* верхнего отступа НЕТ */

.sticky-fuel { position: sticky; top: 0; z-index: 5; }   /* больше ничего */

.sticky-fuel > .card {
  margin: 0;
  box-shadow: 0 12px 16px -14px rgba(0, 0, 0, 0.95);
}

.sticky-fuel.stuck::before {                /* только у прилипшей */
  content: '';
  position: absolute;
  z-index: -1;                              /* ПОД карточкой */
  left: 0; right: 0;
  top: -2px;
  height: calc(var(--radius) + 2px);        /* ровно дуга верхнего угла */
  background: var(--bg);
  pointer-events: none;
}
```

`syncStickyFuel()` (`main.ts`) ставит класс `stuck`: сравнивает
`wrap.getBoundingClientRect().top` с верхом области прокрутки. Вызывается в
конце `render()` и по событию `scroll` на `#content`.

## Три правила, из которых всё следует

1. **Прилипание считается по внешнему краю блока.** Поэтому любой отступ —
   `padding-top` у `<main>`, `margin` у обёртки или у карточки — становится
   щелью над прилипшей карточкой, в которой видно уползающие строки. Отсюда:
   у `<main>` верхнего отступа нет, у обёртки полей нет, у карточки `margin: 0`.
2. **Карточка — непрозрачный прямоугольник со скруглением.** Вне дуги радиуса
   фон не закрашивается, то есть углы прозрачны по определению. Сквозь них
   видно то, что под карточкой, — и это либо нужно (снизу), либо нет (сверху).
3. **Сверху «дырку» можно только закрасить, но не закрыть карточкой.**
   Полоса-подложка лежит под карточкой (`z-index: -1`): там, где карточка
   закрашена сама, её не видно, а в дырках углов она даёт цвет фона. Вся
   обёртка выше списка (`z-index: 5`), поэтому полоса накрывает и уползающее.

## Что уже пробовали — не повторять

| Вариант | Чем кончился |
|---|---|
| Фон у обёртки во всю ширину (отрицательные поля + `padding`) | Пользователь: «карточка остаётся непрозрачным прямоугольником тёмного цвета с нарисованным поверх скруглённым». Тёмная подложка просвечивала в дугах нижних углов (§131.1–§131.6) |
| Прямой низ у прилипшей (`.stuck > .card`) | Углы «дёргаются» на ходу (§131.4, §131.8) |
| «Подошва» — полоса цвета карточки под панелью с тенью | Съедала строку, читалась как лишняя полоса (§131.5, §131.6) |
| Прямой верх у прилипшей | Пользователь: «скругления не должны пропадать» (§131.11) |
| Подгонка `top`/`margin` по пикселям | Не работает: величина щели зависит от браузера |

## Как проверяется

`tools/verify-sticky-fuel.mjs` — **31 проверка**: липкость и `top: 0`,
прозрачная обёртка без полей и отступов, отсутствие верхнего отступа у
`<main>`, неизменность радиусов (16 px сверху и снизу), полоса под верхними
углами (`z-index: -1`, цвет страницы, высота в радиус), отсутствие «подошвы»,
порядок карточек и то, что на других вкладках ничего не липнет.

Состояния проверяются подменой `getBoundingClientRect` (в jsdom они нулевые)
и настоящим событием `scroll` — то есть проверяется поведение, а не только
наличие правила.

## §132.7 — «Станция» на рынке прилипает так же

Пользователь: «Сделай карточку c0 в рынке по принципу „топливо“».

Никакой отдельной механики не понадобилось: карточка «Станция» на рынке
обёрнута в тот же `.sticky-fuel`, и `syncStickyCards()` (бывший
`syncStickyFuel()`) теперь обходит все обёртки в `#content`, а не первую
попавшуюся. На одном экране она всегда одна, но проверять все дешевле, чем
потом искать, почему на новом экране углы не закрасились.

Проверки: `verify-sticky-fuel` **33/33** (+3: на рынке липкая карточка одна,
это «Станция», у неё `position: sticky`).
