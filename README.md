# Elite Idle

Браузерная idle / captain-manager игра по мотивам классической **Elite (1984/1985, BBC Micro)** Дэвида Брабена и Яна Белла.

Все механики (генерация 8 галактик по 256 систем, расчёт цен рынка, характеристики кораблей, урон и цены оборудования) воспроизведены строго по оригинальному ассемблерному коду и эталонному `txtelite.c`.

## 🚀 Особенности

- **8 галактик по 256 звездных систем**: полностью процедурная генерация по алгоритму Фибоначчи из оригинала.
- **Точная экономика**: колебания рынка, 17 оригинальных товаров, совпадение цен с точностью до десятых долей кредита.
- **Боевая система и случайные встречи**: пираты, полиция, торговцы, астероиды, ракеты, ECM и спасательные капсулы.
- **Характеристики кораблей из дизассемблера**:
  - Sidewinder, Viper, Cobra Mk III, Fer-de-Lance, Python, Anaconda и др.
  - Урон врагов рассчитывается по формуле оригинала: `byte#19 >> 1` (где `byte#19 = (laserPower << 3) | missiles`).
  - Цены оборудования соответствуют оригинальной таблице `PRXS`.
- **Ранги**: аутентичная система рангов (от *Безобидный* до *ЭЛИТА*) по 16-битному счётчику убийств (`status.asm`).
- **Idle-формат**: полёты между системами происходят в фоновом режиме по таймеру или с ускорением. Поддерживается сохранение и офлайн-досчёт прогресса.

## 🛠 Технологический стек

- **TypeScript** / pure functions
- **Vite** (без тяжёлых фреймворков)
- **Node.js test runner** (`node --test`) для эталонных тестов

## 📦 Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка проекта
npm run build

# Запуск тестов (120+ тестов)
npm test
```

## 🧪 Тестирование

Проект покрыт автоматическими тестами, сверяющими значения с эталонными исходниками:
- `test/galaxy.test.ts` — процедурная генерация систем и галактик
- `test/reference.test.ts` — сверка рынка с `txtelite.c`
- `test/reference-ships.test.ts` — сверка параметров кораблей и цен оборудования с оригиналом
- `test/reference-equipment.test.ts` — доступность оборудования на верфи по `EQSHP` (`QQ25 = min(tek + 3, 14)`)
- `test/reference-galactic.test.ts` — галактический гиперпрыжок по `Ghy`: прибытие в (96, 96), метрика `TT111`, круговой обход 8 галактик
- `test/reference-spawn.test.ts` — таблицы спавна `XX21`, распределение пиратов и исправление Моксона для Moray
- `test/reference-contraband.test.ts` — контрабанда при взлёте по `BAD`/`TT110` (`legal | (рабы + наркотики) * 2 + оружие`)
- `test/encounters.test.ts` — боевой баланс, встречи, спасательная капсула и полиция
- `test/state.test.ts` — торговля, полёты, сохранение/загрузка
- `test/invariants.test.ts` — инварианты ядра на длинных случайных прогонах: деньги, трюм, топливо, независимость досчёта от разбиения на вызовы, обратимость сохранений
