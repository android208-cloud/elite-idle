# Релизы

Один файл — вся игра. Открывается на телефоне без сервера, без сети и без
интернета: скрипты, стили и экран стыковки лежат внутри.

## Как запустить на телефоне

1. Скачать `.html` из этой папки (или получить файл в чате).
2. Открыть его в браузере телефона.
3. Если браузер открывает как текст — переименовать/открыть через
   «Файлы» → «Открыть с помощью» → браузер.

Совет: добавить на домашний экран — тогда откроется как приложение,
во весь экран, без адресной строки.

## Ограничения `file://`

- **Сохранение в localStorage** на `file://` часть браузеров не даёт.
  Игра это переживает (`try/catch`), но прогресс между запусками может не
  сохраниться. Для сохранения есть «Настройки → Прогресс в файле»:
  выгрузка и загрузка JSON.
- Экран стыковки работает (он внутри файла), но на некоторых встроенных
  браузерах мессенджеров iframe может блокироваться — открывайте в
  настоящем браузере (Chrome/Safari/Firefox).

## Проверка перед выдачей

```
node tools/verify-release.mjs releases/elite-idle-0.2.0.html
```

16 проверок: автономность (ни одной внешней ссылки), запуск по `file://`
без ошибок, отрисовка, пять вкладок, SVG-иконки, экран стыковки внутри,
шапка на каждой вкладке.
